# skill-curator

当前版本：**1.2.1**

`skill-curator` 是面向 Codex 的 GitHub 项目审核、形态判断、适配与授权安装 Skill。它会根据用户意图选择审核、定向查看或直接安装流程，不再把所有请求都强制转换成完整审核。

## 如何使用

### 仅发送 GitHub 仓库主页链接

```text
https://github.com/owner/repository
```

执行默认简洁审核，说明项目是什么、主要功能、适合形态、对当前用户的价值、可能的重复项、代表性同类项目和最终建议。此模式默认不安装。

### 链接加明确任务

```text
https://github.com/owner/repository
查看它的安装方式和 Windows 支持情况
```

先用一句话说明“是什么”，然后只回答明确要求的内容，不强制输出完整审核。

### 明确要求安装

```text
https://github.com/owner/repository
直接帮我安装
```

跳过默认审核，先在后台完成必要检查，再选择最合适的安装或接入方式。只有遇到权限、安装位置、覆盖已有内容、形式转换、付费资源或无法可靠回滚等事项时才询问。

### 没有 GitHub 仓库主页链接

使用 `$skill-curator` 手动触发：

```text
$skill-curator 判断这个本地项目适合做 Skill、MCP、CLI 还是脚本
```

如果没有给出目标或动作，Skill 会要求补充必要信息。

## 首次使用配置

首次实际处理任务前，Skill 会逐项完成配置，并将结果写入个人 `config.yaml`：

1. 是否在安装或接入成功后撰写说明文档。
2. 若需要文档：保存目录，以及是否沿用现有模板或目录内文件的格式。
3. 模板来源：指定文件、当前目录样本、自适应生成，或与 AI 协作制作并保存模板。
4. 本地相关项目和近期对话的扫描深度：轻量或中量。
5. 说明文档失败后的重试策略：每次询问、仅安全场景自动重试一次，或不自动重试。

配置验证通过后才会将 `configured` 设为 `1`。路径失效时先尝试局部修复；无法唯一确认时再询问。只有用户明确要求重配置，或配置整体失效、不兼容时，才重新执行完整配置。

个人配置不会纳入版本控制。升级时保留现有 `config.yaml`，使用 `config.example.yaml` 作为字段参考。

## V1.2.1 结构调整

`SKILL.md` 只保留配置闸门、意图路由、共享证据规则和行为边界；审核、安装与安装后文档规则分别放入按需读取的 reference。配置完成或修复后会继续处理原始请求。V1.2 的触发与执行行为保持不变，`config.example.yaml` 的配置结构也不变。

## V1.2 主要变化

- 按“仅链接、明确任务、明确安装”分流，避免不必要的完整审核。
- 明确安装请求不再先输出审核，只有真正阻塞安装时才确认。
- 新增独立首次使用配置流程和 `config.yaml` 状态位。
- 说明文档可从当前目录最多 5 个 Markdown 文件中非递归提取结构风格。
- 中量扫描默认最多读取 10 个近期相关任务、每个任务 10 轮内容。
- 说明文档失败不回滚已成功的安装，并支持可配置的安全重试策略。
- 安装成功后，尽可能调用已安装的 Obsidian 相关 Skill 撰写文档。

## 仓库结构

```text
skill-curator/
├── SKILL.md
├── config.example.yaml
└── references/
    ├── configuration.md
    ├── audit.md
    ├── installation.md
    └── documentation.md
```

- `SKILL.md`：触发规则、配置闸门、意图路由与共享边界。
- `config.example.yaml`：可分发的配置样例，不保存用户的实际路径。
- `references/configuration.md`：首次配置、配置校验、局部修复和重配置规则。
- `references/audit.md`：仅链接或明确审核请求的审核流程与输出格式。
- `references/installation.md`：明确安装请求的预检、适配、验证与回滚。
- `references/documentation.md`：安装成功后的模板选择、Obsidian 文档和重试规则。

## 行为边界

- 不因普通的软件选型、代码审查或安装请求自动触发；没有 GitHub 仓库主页链接时需显式使用 `$skill-curator`。
- 不自动更新已有工具，不自动卸载旧 Skill。
- 小范围适配可在同一目标内继续；修改范围明显扩大时暂停并征求意见。
- Skill 安装验证失败时回滚本次变更；说明文档失败不撤销已经验证成功的安装。
- 未成功安装或接入的项目不写入说明文档。
